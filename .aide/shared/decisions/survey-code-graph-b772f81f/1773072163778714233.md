# survey-code-graph

**Decision:** Computed on demand via BFS over code index, not stored

## Rationale

Call graph changes with every code edit. Storing it creates a stale-data problem. The code index already has Symbol (with body line ranges) and Reference (with call sites) — BFS traversal at query time is fast enough for interactive use. Requires adding GetContainingSymbol to CodeIndexStore.
