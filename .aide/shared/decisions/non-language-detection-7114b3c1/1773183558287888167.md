# non-language-detection

**Decision:** Labels in index.json, no pack directories for build tools/CI/CD

## Rationale

Creating full pack.json directories for make, task, github-actions etc. is overkill — they have no grammar, queries, complexity, imports, or tokenisation. A label field in index.json is sufficient. Keeps pack dirs for actual languages only.
