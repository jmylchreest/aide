# memory-scoring

**Decision:** Deterministic compute-on-the-fly scoring with category weights, provenance boost, recency decay, and access factor. Two env vars: AIDE_MEMORY_SCORING_DISABLED (master kill-switch) and AIDE_MEMORY_DECAY_DISABLED (recency only).

## Rationale

Score not stored — tunable without data migration. Priority order: user prefs (1.0) > abandoned (0.9) > blocker (0.85) > issue (0.8) > discovery (0.7) > project learning (0.6) > session (0.4). Weights: category 0.5, recency 0.25, provenance 0.15, access 0.1. Half-life 30 days. Manual Priority override (non-zero replaces computed). ULID tiebreaker for equal scores. AIDE_MEMORY_SCORING_DISABLED preserves current chronological behaviour.
