# pack-index-architecture

**Decision:** Single packs/index.json for project markers, entrypoints in per-language pack.json

## Rationale

Project markers (go.mod, Taskfile.yml, .github/workflows) are cross-cutting filesystem detection rules. A single index.json keeps them centralized and avoids creating full pack dirs for non-language tools. Entrypoints stay in pack.json because they are tightly coupled to each language's tree-sitter grammar and code index queries. Index is embedded by default, overridable via .aide/grammars/index.json with merge semantics (disk overrides embedded by File+Kind key).
