# grammar-detection-dual-pass

**Decision:** Project markers AND file scan for grammar detection

## Rationale

Markers give fast project-level detection (finding Cargo.toml implies rust grammar needed). File scanning still catches languages that only appear as scattered files without project markers (bash scripts, random .lua files). Both passes contribute to ScanResult.
