# survey-analyzers

**Decision:** Three analyzers: topology (filesystem), entrypoints (code index), churn (go-git)

## Rationale

Covers the three main questions when onboarding: What is this? (topology), Where do I start? (entrypoints), What changes most? (churn). Each uses a different data source — filesystem, tree-sitter code index, git history. Extensible: new analyzers can be added without changing the store.
