# survey-entry-scope

**Decision:** File-level or repo-level, never line-level

## Rationale

Survey describes codebase structure (modules, entry points, tech stacks) not specific code locations. Line-level granularity belongs to findings or the code index. Keeping entries coarse makes them stable across minor edits.
