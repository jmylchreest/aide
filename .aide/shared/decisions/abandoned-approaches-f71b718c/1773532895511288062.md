# abandoned-approaches

**Decision:** New 'abandoned' memory category with structured content template, stored via skill instructions (no automated detection)

## Rationale

Distinct category is searchable via --category=abandoned, follows blocker/discovery pattern. Skill instructions only for detection — zero false positives, relies on agent compliance. Content template: ABANDONED/REASON/ALTERNATIVE/CONTEXT. Tags: reason:<why>, approach:<what>, project:<name>, source:discovered.
