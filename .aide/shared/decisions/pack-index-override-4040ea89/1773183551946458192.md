# pack-index-override

**Decision:** Merge strategy for disk index.json overriding embedded default

## Rationale

Users/teams can add custom markers or tweak existing ones without maintaining the full list. Entries from disk index.json override matching entries from embedded index by (File, Kind) composite key. Embedded entries not present on disk are kept. Consistent with how LoadFromDir already overrides embedded pack.json files.
