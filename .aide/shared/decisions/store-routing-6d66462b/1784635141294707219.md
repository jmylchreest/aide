# store-routing

**Decision:** Writes default to the nearest scope (chain self). --store=parent routes to chain[1] (nearest container); --store=top to the outermost ancestor; --store=<path> to an explicit CHAIN MEMBER only (siblings/unrelated stores unreachable — that is --project-root's job). Errors are hard and non-silent: no parent in chain → error; target lacks an existing .aide store → refuse with hint (a child must never implicitly bootstrap its parent's store). Tags never route: scope: is audience, origin: is provenance, placement is physical.

## Rationale

Silent misplacement is the bug class the anchor work exists to kill. parent=chain[1] matches containment intuition and is entry-path-independent; top exists because estate-wide decisions are the main upward use case and parent≠root in deep nesting. Confirmed by user 2026-07-21: target must already have .aide.
