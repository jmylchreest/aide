# memory-isolation

**Decision:** Memories and state never leave their project. Only decisions cross project boundaries: the anchor-chain cascade downward, and M2 share subscriptions sync decisions only from remote peers. No scope:descendants/scope:children memory tag exists. Estate-wide guidance belongs in a decision at the estate root; deliberate placement of a memory in a parent uses --store parent, making it the parent's memory.

## Rationale

Keeps the isolation story one sentence long. The estate-rules use case is fully covered by the decision cascade; a tagged memory cascade would add a second crossing mechanism with no distinct need. Confirmed by John 2026-07-21.
