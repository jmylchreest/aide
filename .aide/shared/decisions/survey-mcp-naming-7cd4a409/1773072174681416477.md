# survey-mcp-naming

**Decision:** Four MCP tools: survey_search, survey_list, survey_stats, survey_run

## Rationale

Mirrors findings tool naming (findings_search, findings_list, findings_stats). Added survey_run since survey analysis is explicit (not continuous like findings file watching). Tool descriptions explicitly distinguish survey (structure) from findings (problems) to prevent agent confusion.
