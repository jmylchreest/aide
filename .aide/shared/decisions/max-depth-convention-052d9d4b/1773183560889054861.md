# max-depth-convention

**Decision:** max_depth: 0=root, positive=limit, -1=unlimited within project root

## Rationale

Common convention. 0 is the Go zero-value default (root only when omitted). -1 as unlimited is standard in many APIs. Walk function checks maxDepth >= 0 before applying depth guard.
