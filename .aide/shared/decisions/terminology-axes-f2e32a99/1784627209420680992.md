# terminology-axes

**Decision:** Three orthogonal axes, one word each: scope: = AUDIENCE (injection filter on content; scope:global = inject into all sessions — the only meaning of the word scope); origin: = PROVENANCE (where an injected record came from: origin:parent:<id>, origin:peer:<name>; synthesized at read time); the topology is the ANCHOR CHAIN (self + parent projects, from aide anchor). Write routing uses --store parent, never --scope.

## Rationale

scope: shipped as an audience tag (scope:global excluded from share export, injected everywhere) before topology work began; reusing the word for topology or provenance caused repeated design confusion. Package pkg/anchor, type anchorLink, and all docs say anchor chain.
