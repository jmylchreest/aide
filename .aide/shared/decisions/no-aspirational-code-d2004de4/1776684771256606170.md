# no-aspirational-code

**Decision:** Aspirational, planned, or 'not yet integrated' code must not exist in source files. Plans go in docs/futures.md (or equivalent); source code must be reachable from real call paths.

## Rationale

Aspirational code rots silently, looks indistinguishable from genuine dead code to static analysers, and misleads readers about what is actually used. Documenting intent in a futures doc keeps the codebase honest and analysers signal-rich. Applies to every language in the repo (Go, TypeScript, etc.).
