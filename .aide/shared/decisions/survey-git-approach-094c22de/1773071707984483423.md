# survey-git-approach

**Decision:** Use go-git (github.com/go-git/go-git/v5) for all git operations

## Rationale

Portability: users should not need git installed on PATH. Survey results are cached in BoltDB so the go-git performance penalty (slower blame, log-with-stats) is acceptable since operations run once and persist. Eliminates entire class of unhappy paths (git not found, permission denied on binary). Remaining unhappy paths: not a git repo, corrupt .git, submodule checkout missing.
