# multi-arch-binary-distribution

**Decision:** Ship Go binary via npm optionalDependencies (esbuild-style: 6 per-arch packages @jmylchreest/aide-binary-<platform>-<arch>). OpenCode/Codex get bundled binaries via npm install; Claude Code continues to use download-on-first-use. Resolution MUST follow node's algorithm (require.resolve + node_modules walk-up), not <plugin-root>/node_modules.
